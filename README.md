#Portfolio Project #2 — Furniture Website Layout
###📌 About the Project
A modern, responsive, multi-page website layout for a furniture brand. Built with clean semantic HTML, structured SCSS using BEM methodology, and custom CSS Grid layouts for showcasing design collections. Interactive UI components are implemented with Vanilla JavaScript.
🛠 Tech Stack
 HTML5 (Semantic multi-page architecture)
 CSS3 / SCSS (BEM methodology, CSS Grid & Flexbox)
 JavaScript (Vanilla JS): DOM manipulation & UI interactive elements
 Build Tool: Gulp
 Version Control: Git & GitHub
